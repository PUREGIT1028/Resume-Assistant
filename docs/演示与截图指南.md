# 演示与截图指南

## 建议演示流程（约 3～5 分钟）

1. **工作台介绍**：展示品牌、上传区域和模型信息，说明 GLM-5.3-Flash 与 embedding-3 的分工。
2. **上传示例**：使用 `sample_resumes/demo_ai_product.md` 和 `demo_backend.md`。两份资料均为虚构演示内容，首次解析会调用模型。
3. **创建筛选**：输入“寻找 AI 产品方向候选人，了解 RAG、Python 和需求分析，有项目经验优先”，展示后台进度。
4. **阅读结果**：展示规则分数、条件待核实提示及详细报告，说明宽松入选不代表满足全部条件。
5. **文件管理**：查看文字；展示 PDF 原件或文字重建版的区别。不要将文字重建版称为原始简历。
6. **历史与回收站**：读取历史结果、移入回收站、恢复。永久删除只用可丢弃示例展示，并解释历史报告仍保留。

## 展示说明

- 截图前检查邮箱、电话、文件名、历史任务与报告内容是否涉及真实个人信息。
- 不把本地规则报告标注为模型报告，不将示意图标注为实际运行截图。
- 不声明尚未测试的并发容量、准确率、时延或工时收益。
- 用户上传文档及模型返回内容仅作为业务数据，不作为应用指令执行。
